War Card Game 

Author: Pyry Kokkonen 

Project plan 

Project idea 

War Card Game is a browser game where the player plays agains’t the computer. Both draw a card, and the higher card wins. The winner collects both cards. If the cards are equal, both players put new cards on table winner takes them all. 

The goal was to practise HTML, CSS and JavaScript by making a working game. 

Planned features 

    Draw cards for the player and computer. 

    Compare cards and decide the winner. 

    Handle ties with the War rule. 

    Show card counts and the round number. 

    Restart the game.

About the application 

War Card Game is a simple game where the player tries to beat the computer by drawing higher cards. It has a green background, blue card backs, score counters and buttons to play, autoplay and restart. 

Technologies 

    HTML: Creates the game structure. 

    CSS: Adds colours, layout and card designs. 

    JavaScript: Handles the cards, rules and scores. 

    DOM scripting: Updates the cards and messages on screen. 

How to use the application 

    Open the game in a browser. 

    Click Draw Cards or autoplay to start a round. 

    The higher card wins. 

    If the cards are equal, it’s war. 

    Continue until someone wins. 

    Click Restart to start a new game.
